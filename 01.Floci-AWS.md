## Floci with AWS: 


### Core idea:

_Instead of calling real AWS, your apps talk to:_
```
AWS SDK / Terraform / CLI
        ↓
http://localhost:4566
        ↓
Floci (emulated AWS services)
```



### Prerequisites:
- Docker Installed. 




---
---



## Run Floci Container: 

_Floci directly with Docker:_
```bash 
docker run --name floci -d -p 4566:4566 -v /var/run/docker.sock:/var/run/docker.sock floci/floci:latest
```





> The docs specify `mock=false` as real mode, with k3s launched in Docker, and `FLOCI_SERVICES_EKS_DOCKER_NETWORK` controls the network used by the k3s containers.

Based directly on the documentation, I'd use a dedicated Docker network:

```bash
-- Create Network:
docker network create floci-net


-- Run Container for AWS: 
docker run --name floci -d \
  -p 4566:4566 \
  --network floci-net \
  --group-add 988 \
  -v /var/run/docker.sock:/var/run/docker.sock \
  -e FLOCI_SERVICES_EKS_MOCK=false \
  -e FLOCI_SERVICES_EKS_DOCKER_NETWORK=floci-net \
  floci/floci:latest-compat 
```




> [!IMPORTANT]  
> The old `hectorvent/floci` repository will no longer receive updates.

## Floci with Docker Compose:

_Create a `docker-compose.yml`:_
```yaml
services:
  floci:
    image: floci/floci:latest
    container_name: floci
    ports:
      - "4566:4566"
    volumes:
      - ./data:/app/data
      - /var/run/docker.sock:/var/run/docker.sock
```


```bash
docker compose up -d
```

## Install AWS CLI: 

```bash
curl "https://awscli.amazonaws.com/awscli-exe-linux-x86_64.zip" -o "awscliv2.zip"
```


```bash
unzip awscliv2.zip

./aws/install
```


_AWS CLI Version Check:_
```bash
aws --version


### output:
aws-cli/2.34.36 Python/3.14.4 Linux/4.18.0-477.27.1.el8_8.x86_64 exe/x86_64.rocky.8
```


### Method A: Configure AWS CLI (Recommended)

The terminal will prompt you to enter the following information one by one:

- AWS Access Key ID: Paste your downloaded Access Key ID.
- AWS Secret Access Key: Paste your downloaded Secret Access Key.
- Default region name: Enter your primary AWS region (e.g., `us-east-1` or `eu-west-1`).
- Default output format: Enter your preferred format (e.g., `json`, `yaml`, or `text`).



_AWS Configure:_
```bash
aws configure

AWS Access Key ID [None]: test
AWS Secret Access Key [None]: test
Default region name [None]: us-east-1
Default output format [None]: json
```


_Check configuration:_
```
aws configure list
```



_Or, Configure Custom profile::_
```bash
aws configure --profile aws_dev
```


```bash
aws sts get-caller-identity --profile aws_dev
```




### Method B: Setting Environment Variables (Temporary Setup)


Floci accepts any dummy credentials — no real AWS account needed. Add these to your shell profile `~/.bashrc` or, a single terminal session:
```bash
export AWS_ENDPOINT_URL=http://localhost:4566
export AWS_DEFAULT_REGION=us-east-1
export AWS_ACCESS_KEY_ID=test
export AWS_SECRET_ACCESS_KEY=test
```


```bash
aws configure list
```
